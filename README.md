# Spotify Clone

A Spotify-inspired web player built with HTML, CSS, and JavaScript. Explore the interface, manage your library, and interact with playlists through a responsive browser experience.

[Live Demo](https://spotifycl0ne.vercel.app/)

## Features

- Spotify-inspired music player interface
- Browse playlists and songs
- Manage your library
- User profile, login, and signup pages
- Responsive layout for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` - Main music player interface
- `library.js` - Library and playlist functionality
- `main.js` - Main application interactions
- `style.css` - Application styling
- `login.html` - Login page
- `signup.html` - Signup page
- `profile.html` - User profile page
- `assets/` - Images and other static assets
